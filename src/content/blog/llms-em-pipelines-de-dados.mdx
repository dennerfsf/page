Modelos de linguagem (LLMs) abriram novas possibilidades em engenharia de dados: classificar textos livres, extrair entidades de documentos, enriquecer cadastros e gerar resumos. Mas, dentro de um pipeline, um LLM precisa se comportar como qualquer outro componente: **previsível, validado e observável**.

## Padrão 1 — Peça saídas estruturadas

Texto livre é difícil de validar. Defina um schema e exija que a resposta o siga. Em Python, bibliotecas como o Pydantic tornam isso explícito:

```python
from pydantic import BaseModel, Field, ValidationError

class Classificacao(BaseModel):
    categoria: str = Field(pattern=r"^(reclamacao|elogio|duvida|outro)$")
    confianca: float = Field(ge=0, le=1)
    resumo: str = Field(max_length=280)

def validar_resposta(json_bruto: str) -> Classificacao | None:
    try:
        return Classificacao.model_validate_json(json_bruto)
    except ValidationError:
        return None  # encaminhar para fila de revisão
```

## Padrão 2 — Trate o modelo como dependência externa

- **Idempotência e cache:** a mesma entrada não deve ser processada (e cobrada) duas vezes;
- **Retentativas com backoff** para falhas transitórias;
- **Limites de custo e de taxa** por execução;
- **Versão do modelo e do prompt** registradas junto ao resultado.

## Padrão 3 — Privacidade por padrão

Antes de enviar dados a qualquer serviço, aplique minimização: remova ou mascare dados pessoais que não sejam necessários para a tarefa e verifique se o uso está de acordo com as políticas da organização e com a LGPD.

## Padrão 4 — Avalie continuamente

Mantenha um conjunto de exemplos rotulados e meça a qualidade das respostas a cada mudança de prompt ou de modelo. Resultados com baixa confiança devem seguir para revisão humana.

| Etapa | Controle recomendado |
| --- | --- |
| Entrada | Minimização e mascaramento de dados |
| Chamada | Timeout, retentativa e limite de custo |
| Saída | Validação de schema e limiar de confiança |
| Monitoramento | Métricas de qualidade, latência e custo |

Com esses cuidados, LLMs deixam de ser experimentos isolados e passam a compor pipelines confiáveis e governados.
